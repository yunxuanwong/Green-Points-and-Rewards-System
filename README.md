# Green Points and Rewards System
The Green Points and Rewards System is a web-based system called LeafLink to encourage people to keep a more sustainable lifestyle with their ordinary daily actions. Users are able to participate in various green activities, gain points for what they have done and redeem these points for rewards so they will keep choosing eco-friendly behaviors.

# Roles
1. Participant
2. Administrator
3. Moderator

# Features
1. Participant
- Participant registration
- Participant login authentication
- View and update profile
- View green activities
- Submit green activities
- Check submitted activity status
- View and redeem rewards
- View points and badges
- Join team challenges

2. Administrator
- Administrator registration
- Administrator login authentication
- Manage user accounts
- Manage green activities
- Manage team challenges
- Manage rewards
- Manage badge and achievements
- View system reports
- View abnormal reports
  
3. Moderator
  - Moderator registration
  - Moderator login authentication
  - Approve rewards
  - Approve submitted activities
  - View leaderboard
  - Genrate reports
